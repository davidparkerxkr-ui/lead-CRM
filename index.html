Calling setup

How the big Call button behaves. RingCentral on the web is the setup you use in Brave.

  1. Open app.ringcentral.com in Brave and sign in to RingCentral.
  2. Pin that tab so the web phone is always one click away.
  3. Back here, hit CALL IN RINGCENTRAL — the first tap opens the RingCentral tab, later taps reuse that same tab. The number is copied every time.
  4. In RingCentral, click the dialpad, press Ctrl+V to paste, and dial.
